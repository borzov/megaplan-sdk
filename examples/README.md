# Megaplan SDK Examples

Примеры использования Megaplan Python SDK для различных сценариев.

## CLI App (`cli_app/`)

Интерактивное консольное приложение для тестирования всех возможностей SDK.

### Основные возможности:

**Работа с задачами (Tasks):**
- Список, поиск, создание задач
- Итерация по всем задачам с пагинацией
- Управление комментариями
- **Управление участниками** (наблюдатели и соисполнители)
- **Управление вехами** (milestones)
- **История изменений** с поиском

**Работа с проектами (Projects):**
- Список, поиск, создание проектов
- Управление комментариями
- **Управление участниками** (наблюдатели и соисполнители)
- **Управление вехами** (milestones)
- **История изменений** с поиском

**Работа со сделками (Deals):**
- Список, поиск, создание сделок
- Управление комментариями
- **Управление наблюдателями** (auditors)
- **История изменений** с поиском

**Дополнительно:**
- Работа с контрагентами (Contractors)
- Управление комментариями
- Сотрудники (Employees) - список, поиск, информация о текущем пользователе
- Загрузка файлов (Files)

### Запуск:
```bash
cd examples/cli_app
python -m pip install -r requirements.txt
python main.py
```

## Требования

- Python 3.11+
- Учетная запись Megaplan
- Настроенный инстанс Megaplan (https://yourcompany.megaplan.ru)

## Настройка

Для всех примеров нужны credentials от Megaplan:

1. **URL**: адрес вашего инстанса (например, https://company.megaplan.ru)
2. **Username**: email пользователя
3. **Password**: пароль

Credentials можно передать:
- Через переменные окружения (`.env` файл)
- Через аргументы командной строки
- Интерактивно при запуске

## Безопасность

⚠️ **Важно**: Примеры предназначены для демонстрации и тестирования.

- Не используйте production credentials в примерах
- Не коммитьте `.env` файлы с реальными данными
- Используйте test/staging окружение для экспериментов
